Mengapa Komputer Butuh Variabel? 

- Komputer tidak punya ingatan permanen otomatis. 

- Tanpa variabel, data dilupakan dalam 1 milidetik. 

- Variabel bertugas menyimpan nama, harga, atau data tren bisnis. 

## Anatomi Menulis Variabel 

- nama_toko = "Kopi Bahagia" 

   - nama_toko -> Nama variabel/label. 

   - = -> Aksi memasukkan data. 

   - "Kopi Bahagia" -> Isi data di dalam kotaknya. 

# Tipe Barang di Dalam Kotak 

- Teks (String): Wajib pakai tanda petik, misal "Budi". 

   - Angka Bulat (Integer): Tanpa petik, misal 25. 

   - Angka Desimal (Float): Pakai tanda titik, misal 4.5. 

# Mengapa Tipe Data Penting? 

   - Angka + Angka: 5 + 5 = 10 (Perhitungan matematika). 

   - Teks + Teks: "5" + "5" = "55" (Menggabungkan kata). 

- Komputer memproses data berdasarkan jenisnya! 

### Berkenalan dengan 'Parameter' 

Variabel = Kotaknya. Parameter = Tombol Pengaturnya. 

Analogi: Slider kecerahan foto di Instagram (skala 1-100). 

Angka setelan yang digeser itulah parameter. 

#### Contoh Parameter Dunia Nyata 

Ojek Online: radius_pencarian = 5 (jarak maksimal 5 km). Video Streaming: mode_hemat = True (kualitas video diturunkan). 

Letak Parameter di Dalam Kode 

- Parameter selalu berada di dalam tanda kurung ( ) setelah fungsi. • data.head(5) -> tampilkan 5 baris data. 

   - data.head(20) -> tampilkan 20 baris data.
